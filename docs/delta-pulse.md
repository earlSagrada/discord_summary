# 增量脉搏：只讲「变了什么」

## 要解决的问题

`cycle.py` 每 15 分钟推一条。同一天里群里聊的往往还是那几件事，如果每轮都让 AI
重新总结一遍当天讨论，用户看到的就是**同一句话被换个说法说 96 遍**——看得累，
而且看不出趋势。

我们要的是：**第 5 条应该告诉我，和第 4 条比又发生了什么。**

## 两层设计

变化分两种，处理方式完全不同。

| | 确定性变化 | 叙事变化 |
|---|---|---|
| 例子 | 灯色从 🟡 变 🟢、价格今天累计 +3.2%、讨论次数 +13 | 有人改口了、争论有结论了、出现了新证据 |
| 谁来算 | [`src/delta.py`](../src/delta.py)，纯 SQL + Python | AI，但喂给它"已经说过的话" |
| 为什么 | 数字必须可验证，让模型算就会编 | 语义变化只有模型能判断 |

### 第一层：`delta.py`（不花钱、不会编）

```
snapshot()  →  今天已有的状态（每票的首次/最近记录、上轮提及数、已推过的简报）
compute()   →  和本轮结果对比，产出结构化差异
render()    →  渲染成「🔄 和上一轮相比」块
```

**关键约束**：`snapshot()` 必须在 `signals.analyze(save=True)` 写库**之前**调用，
否则本轮自己的记录会污染"上一轮"的基准。`cycle.py` 里它在第 3b 步，`analyze` 在第 5 步。

算出来的四类变化：

| 类型 | 判定 | 输出示例 |
|---|---|---|
| 评级变化 | 本轮 light ≠ 今天最近一次记录的 light | `SOXL 评级升级：🔴→🟢，新增关键位突破确认` |
| 首次进榜 | 今天的 signals 表里没出现过 | `QQQ 今天首次进榜（🟡）：reclaim 50日线` |
| 讨论升温 | 本轮提及累计数 − 上一轮累计数 ≥ `HEAT_MIN`(3) | `7709.HK 刚被提起：这段时间又被说了 13 次` |
| 价格进展 | 相对今日首次记录或上轮 ≥ `MOVE_MIN_PCT`(1.0%) | `NVDA 走到 227.98：较上轮 +0.4%，今天累计 +3.0%` |

两个去噪规则，都是为了不制造新的重复：
- **一票一条**：同一只票只出优先级最高的那条（评级 > 首次 > 升温 > 价格）。
- **红灯/无信号的新票不报"首次进榜"**——那只是有人提了一嘴而已。

提及次数为什么能这么算：`cycle` 每轮都对**当天全文**抽标的，所以 `mentions.count`
是当天累计值。「本轮累计 − 上轮累计」正好就是这一轮里新增了多少次讨论。

### 第二层：喂记忆给 AI

`store.pulse_rounds` 表记下每一轮**实际推给用户**的简报正文和「今日主线」。
下一轮 `pulse.summarize()` 把最近 3 轮的正文塞进 prompt 的「今天已经推送过的内容」段，
prompt 第一条规则就是：

> 凡是「已经推送过的内容」里说过的事，除非出现了新进展，否则**一个字都不要再写**。

输出结构也跟着改了：

| 段落 | 作用 |
|---|---|
| 🆕 新增了什么 | 只写旧简报里没有的。没有就明说"没有新话题" |
| 📈 旧话题有什么进展 | 有新证据 / 有人改口 / 价格验证或证伪了之前的说法 |
| 🧊 是不是已经被消化了 | priced-in 判断（见 [priced-in.md](priced-in.md)） |
| 🧭 今日主线 | 一行，20 字内。存回 `pulse_rounds.thread`，下一轮判断是延续还是转折 |
| ⚠️ 存疑 | 没证据的说法 |

「今日主线」由 `pulse.extract_thread()` 从简报里抠出来。它是这条链路里唯一的
跨轮语义状态：下一轮 prompt 会问"这段讨论是推进了这条主线，还是主线变了"。

## 格式强制

模型对格式的服从度时好时坏（有时加粗标题、有时不加）。所以 `pulse.tighten()`
用代码兜底，不靠模型自觉：

- `# 标题` → `**标题**`（Discord 里 `#` 会渲染成超大字号）
- 以 🆕📈🧊🧭⚠️ 等开头、又不是 bullet 的行 → 自动加粗
- 删掉所有空行

## 消息长什么样

```
🕒 交易脉搏 · 08-27 18:04 UTC · 今日第 2 条
🔄 和上一轮相比
- QQQ 今天首次进榜（🟡）：reclaim 50日线。
- 7709.HK 刚被提起：这段时间又被说了 13 次（今天共 13 次）。
🆕 新增了什么
- Frank 再次强调油价还有上升空间…… [B]
📈 旧话题有什么进展
- 暂无进展。
🧭 今日主线
Frank 高度谨慎，止盈缩杠杆应对不确定性。
📊 交易信号 · 18:04 UTC
…
```

第一条不带「🔄 和上一轮相比」（没有可比对象），标题也不带"今日第 N 条"。

## 调参

| 参数 | 位置 | 默认 | 含义 |
|---|---|---|---|
| `HEAT_MIN` | `delta.py` | 3 | 讨论增量多少次才算升温 |
| `MOVE_MIN_PCT` | `delta.py` | 1.0 | 价格变动多少才值得单独说 |
| `max_lines` | `delta.render()` | 6 | 变化块最多几行 |
| 记忆轮数 | `delta.snapshot()` | 3 | prompt 里带最近几轮简报 |

## 故障处理

变化计算失败不会中断推送——`cycle.py` 里 `snapshot`/`compute` 都包了 try，
失败就记一行日志、按首轮处理。`remember_round()` 写记忆失败同理。
推送本身永远优先。
