# 请按下面的结构输出 Markdown

## TL;DR
3~5 行，中文，说人话。要包含：今天最值得记住的一个判断、我们分析上最大的一个短板、明天要重点盯什么。
这段会直接推送给用户，所以**不要出现"材料三"这类内部说法**。

## 一、谁说对了，以及他是怎么得出来的
只写**能验证**的：这个人给出了明确观点或价位，并且今天的价格/消息已经证实或证伪了它。
每人一段，必须包含四件事：
1. 他说了什么（原话要点 + 时间）；
2. 他给的**理由和推理路径**（这是重点——我们要学的是方法，不是结论）；
3. 结果如何（被验证 / 被证伪 / 还没到验证时间）；
4. 这个推理路径能不能复用，什么条件下能复用。
没有人给出可验证的观点，就写"今天没有可验证的观点"，不要硬凑。

## 二、可以沉淀的方法
把上面学到的、以及从 Frank 复盘里学到的，写成 1~4 条**可执行的判断动作**。
- 每条一行，`- ` 开头，写成"遇到 X 情况 → 检查 Y → 得出 Z"这种可以照着做的形式。
- **不要重复 playbook 里已经有的条目**。确实没有新东西就写"（今天没有新方法）"。

## 三、我们分析的不足
对照材料二（我们自己的输出）和材料四（Frank 的范式），诚实地找差距。1~3 条。
每条要具体到"某条简报里我们说了什么，本该怎么说"。常见的差距方向：
- 只说结论没说传导机制；
- 只给了一个方向没给情景路径；
- 关键位只有单一来源，没有交叉确认；
- 没给证伪条件；
- 该判断 priced-in 的地方没判断。

## 四、明天重点关注
1~3 条。哪些事件、哪些价位、哪些说法需要跟进验证。要给出**具体的验证条件**。

## 五、VIP 名单建议
- 建议加入：谁、为什么（必须基于本次观察到的可验证记录）。
- 建议移出：谁、为什么（长期只喊方向不给理由、或多次被证伪）。
- 没有建议就写"维持现状"。
