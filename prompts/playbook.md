# 分析方法库（playbook）

这个文件是**自我改进闭环的载体**：`src/selfreview.py` 每天从群里的讨论、我们
自己推过的简报、信号回测结果、以及 Frank 的 Substack 复盘里提炼出可复用的推理
套路，写进这里；`src/pulse.py` 每轮生成简报时，会把靠前的若干条注入 prompt，
当作分析指引。

**规则**：
- 一条一行，`- ` 开头，写成**可执行的判断动作**，不要写成感想。
- 越靠前权重越高（pulse 只取前 8 条）。selfreview 会把最近验证有效的往上挪。
- `## 已淘汰` 下面的条目不会注入 prompt，保留是为了记住"试过但没用"。

- **月末再平衡叠加识别**：遇到月末最后一个交易日出现单边趋势+波动率放大→检查是否有基本面催化剂→如果没有，标记为"技术性波动+再平衡叠加"→预期下一交易日惯性延续、第三交易日反转→但如果有基本面催化剂（数据、财报、政策），则这个框架失效。
- **横盘整理中的机会识别**：当一个资产"横盘整理 + 走势比对标资产好"时（如 BTC 比黄金稳、但 KOL 被冲散）→ 这是情绪和价格背离的信号 → 等待确认反转后是低波动入场窗口。参考 dnnth 17:52 的观察。
- **买点风险分级 + 仓位匹配**：把同一个方向的入场时机分成"高风险抄底"和"确认后建仓"两类 → 前者用 10-20% 仓位试探，后者用 50-70% 仓位建仓 → 必须事先定义什么叫"确认"（具体价格/量能/形态）。参考 dnnth 的第一类/第二类买点框架。
- **双情景分析的证伪条件检查**：当用"路径一 + 路径二 → 共同项"得出结论时 → 主动问"有没有路径三能让共同项失效" → 如果有，那就是证伪条件，必须同时给出；如果没有，说明分析更稳健。参考 whz20024117 对大金牛的补充。
- **「关键位突破(量不足)」是反向信号**：当系统检测到突破但量能不足时 → 这不是机会，而是陷阱 → 要么不做，要么反向（做空突破方向）。T+1/T+3/T+5胜率均为10%，平均亏损-2.57%/-7.13%/-9.19%（n=10）。
- 一致性拥挤的仓位最危险：当所有人都站在同一边时，反向导火索会引发踩踏。留意"大家都这么想"的说法。
- 先问「这个消息是不是已经在价格里」：消息出了但价格不按预期走，说明是二阶反应（sell the news），方向要反过来想。
- **矛盾信号的拆解优先级**：当两个市场信号矛盾时（如Bear flattening + term premium同时上升）→拆解哪个是确定性操作、哪个是情绪性反应→确定性操作（如Bessent回购）会最终压倒情绪性波动（市场对不确定性的过度定价）→给出验证条件（具体价位或时间窗口）。
- **从Frank的Bessent Put分析学到的七层拆解法**：政策干预类事件要拆到底层传导链：政策工具（回购）→直接影响（压低收益率）→压力转移（美元贬值）→连锁反应（黄金上涨）→二阶效应（制度信誉侵蚀）→长期影响（资本流入意愿）→受益/受损资产（超大规模科技/外国债券持有者）。每一层都要是**可验证的传导机制**，不是猜测。
- **分批止盈的具体操作**：到达统计位置（2 标准差、历史高点、期权 Gamma 墙）时，先 trim 50-70%，保留 30-50% 赌加速。如果回调就加回来，如果继续涨还有暴露。这比"全清 or 全留"在波动市场中更优。
- **对冲仓位的动态管理**：当对冲的前提条件发生变化时（如 IWM put 是对冲衰退，但 IWM 反弹 = 不是衰退），立即平仓而不是等到止损。对冲是为了保护组合，不是为了赚钱。
- **"利好不涨"是比"利空下跌"更强的做空信号**：当一个票在好消息（财报 beat、政策利好）出现后不涨反跌，说明边际买盘枯竭，是做空的确认信号。单纯的"利空下跌"可能只是情绪宣泄，反弹后还会回来。
- **杠杆 ETF 的仓位管理铁律**：3 倍杠杆 ETF（如 UB）不能用"股票思维"持有。必须设置具体的加仓线（如 10Y 跌破 4.64%）和止损线（10Y 突破 4.75%），到达目标区间时必须 trim，不能因为"趋势还在"就全留。
- **业务本质质疑 > 技术面反弹**：当一个票反弹但核心问题（融资结构、下游需求、killer app）没有在财报中解决时，反弹是止盈机会而不是追高信号。参考 Frank 对 NVDA 的判断："融资平台没解释清楚 + 找不到下一个 killer app = 反弹出货"。
- **风险事件前 24 小时降杠杆是纪律**：在央行官员演讲、关键财报、政策发布会前一天，主动把现金比例提到 50% 以上、缩小杠杆量。"不要装逼"是可执行的操作指令，不是建议。
- 拆因果链要拆到底层变量：政策 → 利率 → 汇率 → 资产价格。当一个价格被人为锁住时，压力不会消失，会从另一个价格释放出来（例如压住长端收益率 → 美元贬值 → 黄金上涨）。
- 关键位要用多个来源交叉确认：期权支撑位、Gamma 墙、20 日高/低、50 日线聚在同一区间时，那个区间才是真的分水岭。
- 给出观点必须同时给出证伪条件：什么价格、什么数据出现时说明我错了。没有证伪条件的观点标为「未证实」。
- 把事件拆成情景路径而不是单一预测：列出 2~3 条路径、各自的触发信号和对应仓位，比赌一个方向有用。
- 方向对了不等于赚钱：利润保护（移动止损、分批止盈）和判断方向同样重要，浮盈回吐是最常见的亏损来源。
